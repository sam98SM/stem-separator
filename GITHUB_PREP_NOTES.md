# GitHub preparation notes

This repository was prepared from the uploaded Ultimate Vocal Remover GUI source archive for personal use.

Repository hygiene:
- user audio and generated exports are ignored;
- downloaded model weights are ignored;
- local caches, virtual environments and secrets are ignored;
- UVR is pinned as an upstream submodule so its original history and attribution stay intact;
- no UVR source-code behavior has been changed yet.

The uploaded archive did not contain a standalone LICENSE file. Verify upstream and individual model terms before redistributing model weights.
